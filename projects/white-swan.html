03 Case Study // Commercial Digital Platform

White Swan Holidays

Responsive commercial booking engine, itinerary catalog, and automated customer lead generation pipeline deployed on Render.

Client
White Swan Holidays
Architecture
React + Node.js + Express
Cloud
Render Cloud Platform
Live Domain
Live on Render ↗

01 // Problem Statement

White Swan Holidays, an established luxury travel agency in Ahmedabad, handled high-ticket domestic and international holiday bookings through offline consultations and manual brochure sharing. The lack of a unified digital booking engine led to lost client leads, slow response times, and limited visibility on modern search engines.

02 // The Engineering Solution

I engineered a high-performance, mobile-optimized multi-page digital catalog. Prospective travelers can browse bespoke travel itineraries, submit dynamic booking inquiries, and initiate instant direct messaging with tour consultants via integrated WhatsApp Business deep links.

03 // My Technical Contributions

  • Architected the responsive user experience with React, JavaScript, and Tailwind CSS.
  • Built Express and Node.js backend endpoints for parsing customer inquiries and sending automated notification emails.
  • Optimized performance metrics to achieve 98+ PageSpeed scores and sub-second First Contentful Paint.
  • Configured production continuous integration and hosting on Render Cloud with custom domain routing.

04 // Technology Stack

React Node.js Express Tailwind CSS WhatsApp API Render Cloud
