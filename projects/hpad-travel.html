LIVE ON RENDER ENTERPRISE BUSINESS APPLICATION

HPAD Travel Management System

A web-based employee travel and site visit management platform designed to digitalize travel requests, flight bookings, employee movements and centralized administrative management with multi-tier role authorization.

Launch Live Render App GitHub Repository
hpad-travel-jyxx.onrender.com/
Next.js 15 App Router

Problem Statement

Corporate engineering teams and site engineers frequently travel to remote project sites. Managing travel requests through fragmented email chains, Excel spreadsheets, and manual approvals resulted in delayed flight bookings, lost travel vouchers, zero visibility into employee movements, and administrative chaos.

Project Objective

Engineer a centralized, secure web platform to digitalize the entire travel lifecycle: from initial employee travel requests and multi-tier managerial approval workflows to automated PDF ticket voucher issuance, expense tracking, and real-time administrative analytics.

Solution Overview

The HPAD Travel Management System was architected using Next.js 15 (Turbopack, App Router) and React 19, backed by Supabase (PostgreSQL) with strict Row-Level Security (RLS) policies. The platform provides a unified portal with three distinct access roles:

Employee Role

Submit trip requests, select destinations and travel dates, upload receipts, and download generated PDF travel vouchers.

Admin Approver

Review pending trip requests, verify travel budgets, approve or reject movements with comments, and coordinate logistics.

Super Admin Control

Master control dashboard with real-time Recharts visualizations, employee directory management, and one-click Excel data export.

Key Architectural Features

Role-Based Access Control (RBAC): Strict middleware authentication and Supabase SSR session validation.
Real-Time Analytics Dashboard: Interactive expense charts and employee site distribution via Recharts.
Automated Excel Reporting: Dynamic spreadsheet generation using ExcelJS for payroll and audit reconciliation.
PDF Voucher Issuance: Client-side and server-side travel ticket voucher rendering via jsPDF & AutoTable.
