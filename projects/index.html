PROJECT 01 // AGRI-TECH AI | Computer Vision + LLM

KisanMitra – AI Krishi Officer

Multilingual Crop Pathology & Voice-Enabled Advisory Assistant
Problem Statement: Rural farmers lack accessible agronomy experts when crops develop fungal or pest blight, leading to high crop yield losses and pesticide misapplication.
Project Objective: Deliver instant leaf disease identification from mobile camera uploads and voice advisories spoken in Gujarati and Hindi for maximum accessibility.
Solution Overview:

Constructed an end-to-end Python Flask inference pipeline connecting a convolutional neural network (PyTorch/ResNet) crop disease classifier with OpenAI API dosage generation. Results are converted into localized Gujarati and Hindi speech prompts.

Key Features:
Foliage image disease scan (>90% conf)
Gujarati & Hindi speech synthesis
Precise chemical dosage calculation
Outbreak mapping & SQLite history
Technology Stack:
Python Flask PyTorch / CNN OpenAI API Speech Synthesis SQLite
My Contribution: Lead AI Developer for SIH 2025; engineered computer vision model pipeline, prompt safety rules, and Flask backend.

PROJECT 02 // ENTERPRISE PLATFORM | Full-Stack Cloud App

HPAD Travel Management System

Digital Employee Travel & Site Visit Operations Platform
Problem Statement: Corporate travel coordination relied on paper trails, emails, and static spreadsheets, causing booking delays and lack of visibility into engineer site movements.
Project Objective: Digitalize travel requests, flight booking coordination, approval hierarchies, and expense tracking into a secure, role-based cloud platform.
Solution Overview:

Built with Next.js 15 App Router, React 19, and Supabase (PostgreSQL). Provides granular Role-Based Access Control (Employee, Admin, Super Admin), real-time Recharts dashboards, and automated PDF/Excel movement reports.

Key Features:
Role-Based Access Control (RBAC)
Recharts analytics visualization
Automated Excel reporting (ExcelJS)
PDF travel vouchers via jsPDF
Technology Stack:
Next.js 15 React 19 TypeScript Supabase (PostgreSQL) Tailwind CSS v4 Render Cloud
My Contribution: Full-stack software architecture, schema design, authentication middleware, PDF/Excel export routines, and Render deployment.

PROJECT 04 // MACHINE LEARNING | Predictive Analytics

Loan Default Prediction Model

Supervised Learning Credit Risk Classification Pipeline
Problem Statement: Financial lending institutions incur significant losses due to inaccurate borrower credit risk classification and imbalanced historical loan datasets.
Project Objective: Develop a predictive classification pipeline that preprocesses multi-attribute financial records and forecasts the probability of loan default with high precision.
Solution Overview:

Applied Exploratory Data Analysis (EDA), feature engineering, KNN missing-value imputation, and SMOTE resampling. Evaluated Random Forest, Logistic Regression, and Decision Trees using 5-Fold Stratified Cross Validation.

Key Features:
ROC-AUC 0.884 performance
DTI & Revolving Credit Gini rankings
SMOTE class imbalance mitigation
Confusion matrix metric reporting
Technology Stack:
Python Pandas NumPy Scikit-learn Matplotlib / Seaborn
My Contribution: End-to-end data pipeline, feature scaling, model training, cross-validation, and metrics analysis.

PROJECT 06 // DATA PIPELINE | Automated ETL

Web Scraping & Data Aggregation Pipeline

High-Throughput Asynchronous Extraction & Sanitization Engine
Problem Statement: Manually compiling commercial directory and market intelligence data across fragmented websites is tedious, error-prone, and unsustainable.
Project Objective: Develop an asynchronous, resilient scraping pipeline that harvests thousands of structured records per hour while respecting rate limits and handling schema drift.
Solution Overview:

Python architecture using Asyncio, Aiohttp, and BeautifulSoup. Includes resilient retry logic, automated DOM sanitization, deduplication hashing, and export pipelines to CSV, JSON, and Parquet.

Key Features:
16 parallel worker threads
Automated DOM entity sanitization
Duplicate elimination hashing
Direct export to CSV, JSON & Parquet
Technology Stack:
Python 3 Asyncio / Aiohttp BeautifulSoup4 Pandas JSON / Parquet
My Contribution: Thread pooling architecture, rate limiter implementation, and data sanitization routines.
