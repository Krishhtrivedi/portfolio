You can also run or view it anytime using:

### Option 1: Local Python Server
```bash

```

### Option 2: Direct File Open
Double-click `index.html` or in terminal:
```bash
open index.html
```

### Option 3: Node / NPX Serve
```bash
npm start
# or: npx serve .
```

## 🌐 Free One-Click Deployment Options

### GitHub Pages (Free)
1. Push this folder to a GitHub repository:
   ```bash
   git init
   git add .
   git commit -m "feat: portfolio with AI tools, AWS certification, and business development"
   git branch -M main
   git remote add origin https://github.com/<your-username>/portfolio.git
   git push -u origin main
   ```
2. In your repo: **Settings** > **Pages** > Select branch `main` and root `/` > **Save**.

### Netlify (Free Drag & Drop)
1. Head over to [Netlify Drop](https://app.netlify.com/drop).
2. Drag and drop this `Portfolio` folder.
3. Your site is live in seconds with free SSL.
